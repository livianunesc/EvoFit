A versão principal agora é Python/Flask + MySQL (banco evofit_academico).
Autora: Livia Nunes Coelho
Leia README.md e LEIA PRIMEIRO.txt antes de executar.

Preserve .env, .env.academico, bancos, volumes, SQLite antigo e backups.
Não importe banco/schema.sql por cima das tabelas da edição antiga.
A edição PHP anterior continua em static/, php/, database/ e legacy/.
Nenhuma migração automática dos seus dados antigos é feita nesta adaptação.

Docker: python tools/docker_academico.py iniciar
Se mudar dependências: python tools/docker_academico.py iniciar --rebuild
Não execute docker compose down -v: isso apaga volumes.
